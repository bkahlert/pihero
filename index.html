Pi Hero apt repository

Debian packages that turn a Raspberry Pi running Raspberry Pi OS Lite (Trixie) into a Pi Hero device: pihero (boot configuration, MOTD, watchdog) and pihero-avahi (the device in Finder with a model icon). The packages, their source, and the device files that install them on first boot live at github.com/bkahlert/pihero.

Add the repository

The flat repository at /pihero/apt is signed with the key whose fingerprint is DE60 9D7F F5BE 430D AC8C C807 081F 70E6 A077 DF7A. Device files embed it; on an existing system:

curl -fsSL https://bkahlert.github.io/pihero/apt/pihero-apt.asc | sudo tee /etc/apt/keyrings/pihero.asc >/dev/null
sudo tee /etc/apt/sources.list.d/pihero.sources >/dev/null <<'SOURCES'
Types: deb
URIs: https://bkahlert.github.io/pihero/apt
Suites: ./
Signed-By: /etc/apt/keyrings/pihero.asc
SOURCES
sudo apt update && sudo apt install pihero pihero-avahi
